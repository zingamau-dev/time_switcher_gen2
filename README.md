# Time Switcher

### A Time Control Utility for Pokémon Gen 2 Recomp

**Version:** 1.0.0

Time Switcher adds a simple, convenient sub-menu to your START menu, allowing you to change the game's time of day at will. This is especially useful for hunting time-exclusive wild Pokémon (like Hoothoot at night or Ledyba in the morning) without having to manipulate your device's system clock.

## How to Use

1. Open your **START menu**.
2. Select the **TIME** option (located just above SAVE).
3. A sub-menu will appear. Choose your desired time:
   * **AUTO:** Reads your real-world clock (Standard vanilla behavior).
   * **MORN:** Forces the game into Morning.
   * **DAY:** Forces the game into Day.
   * **NITE:** Forces the game into Night.
4. The menu will close automatically and apply the visual and encounter changes instantly.

## Installation

Download `time_switcher_gen2-1.0.0.zip` from the [Releases](https://github.com/zingamau-dev/time_switcher_gen2/releases) page, then in the game:

**Launcher → MODS → Import mod .zip**, or in a running game
**START → MODS → Import mod .zip**.

Because this mod includes its GitHub repository in the manifest, the launcher will keep it up to date automatically. When a new version is published, you can install it directly from the launcher's **Find mods** tab.
